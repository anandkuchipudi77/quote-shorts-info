Privacy Policy

Quote Shorts Automation — Updated September 29, 2026

About this project

Quote Shorts Automation is a personal tool for creating and uploading quote videos to the owner's YouTube channel. It uses YouTube API Services and does not offer public registration.

Information used

The tool processes video files, titles, descriptions, privacy settings and publication times. It uses Google OAuth tokens to authorize uploads and processes upload responses, including video IDs and status information. Google handles sign-in; the tool does not collect Google passwords.

Purpose and sharing

Information is used to create, upload, schedule and troubleshoot the owner's videos. GitHub processes workflow files and execution data. Google and YouTube receive the uploaded videos and metadata. Stock-media services receive search requests for background footage. Google authorization tokens are not intended to be shared with stock-media services.

This project does not sell personal data or use Google account data for advertising. Videos become publicly visible according to their selected publication settings.

Storage and retention

Cloud authorization credentials are stored in GitHub Actions secrets. Workflow logs may contain video IDs, upload status and diagnostic information. Logs and temporary video artifacts follow the repository's retention settings. Credentials remain configured until the owner removes or replaces them. Uploaded videos remain on YouTube until deleted there.

Stop access and delete data

The owner can disable the GitHub workflow and revoke Google access through Google Account connections . Revoking access does not automatically delete stored files or uploaded videos.

To remove stored data, the owner can delete the relevant GitHub secrets, workflow logs and artifacts, and any local credential or video copies. Uploaded videos can be deleted separately through YouTube Studio.

This website

This information site has no sign-in form, advertising or custom analytics. GitHub Pages may log visitor IP addresses for security. See GitHub's Privacy Statement .

Google and YouTube

See the Google Privacy Policy. Use of this tool is also subject to the YouTube Terms of Service.

Contact

For questions about this policy, contact the project owner through the project's issue page . Issues are public: never include passwords, tokens, credentials or private account information.
