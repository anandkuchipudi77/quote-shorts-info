Quote Shorts Automation

A personal project for creating English quote videos and uploading them to the owner's YouTube channel.

What the application does

The application combines quotes, background footage and music to create short videos. It uses the YouTube Data API to upload videos and set their publication schedule.

Google account access

The channel owner authorizes YouTube upload access through Google OAuth. This project is intended for the owner's personal use and is not a public sign-up service.
